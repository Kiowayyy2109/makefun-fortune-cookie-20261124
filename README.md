One original line of fortune-cookie wisdom for a software developer,
written for the [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
competition on make.fun:

> The bug you fear most is already fixed in the branch you forgot to merge.

The line is 73 characters long, within the competition's 120-character limit.
It is a fortune, not a slogan: the bug a developer dreads is not lurking ahead —
it is already solved behind them, in work they forgot they did.

## Run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). The program raises a `ValueError` if the
line ever exceeds 120 characters.
